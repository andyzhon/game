# 远征

六关原创浏览器冒险游戏，专注即时动作、体力调度与打断反击，包含 18 件特色装备和全球排行榜。

- 前端游戏：`public/game/`
- 在线战绩接口：`app/api/`
- 数据库结构：`db/schema.ts`，迁移：`drizzle/`
- 公开入口：https://mosslight-odyssey.andyzhon0929.chatgpt.site

## 操作

WASD / 方向键移动，J 普攻，K 闪避，L 气功，F 喝药，B 装备背包。

## 战绩

开始时填写昵称。每次通关或战败后保存到云端，并进入即时动作榜单。
“我的战绩”使用当前浏览器的匿名标识读取最近 30 场结果；全球榜单展示即时动作前 30 场成绩；我的战绩保留历史模式成绩。网络失败时暂存待上传结果，可在结算或排行榜中重试。不会存储邮箱、真实姓名或位置。

## 即时动作策略

闪避消耗 30 体力，气功消耗 45。普攻每次命中回复 6 体力；消耗后 0.7 秒开始每秒恢复 16 点，体力上限 100。走位不消耗体力。

临近受击时闪避可获得 5 秒蓄势并返还 15 体力；下一次气功伤害 +50%，且可以打断首领。普通气功可打断普通魔物的蓄力，造成 0.8 秒停顿和 2 秒破绽。破绽期间伤害 +25%，符甲减伤失效；敌人招式结束后也有短暂破绽。

背包、排行榜、帮助、暂停和升级选择会冻结战斗及体力、蓄势计时。营地恢复体力并清除蓄势，战败重试恢复入关快照。

原单人回合制、按回合推进的合作玩法及相关工具入口已移除；房间接口返回 410，新建战绩仅支持 action。数据库迁移和历史战绩保留，旧成绩仍可查看，已有战绩的结算重试保持兼容。

七种武器拥有独立原创 SVG，装备栏、背包、商店与角色持有武器共用对应图片。营地买入新武器会立即自动装备，旧武器留在背包。

## 本地开发

`npm run dev -- --port 4173 --hostname 127.0.0.1`

生成数据迁移：`npm run db:generate`。修改结构时追加迁移，勿重写已发布迁移。

构建后使用 `dist/server/wrangler.json` 将未应用的 SQL 迁移应用到本地 D1，持久化目录为 `.wrangler/state`。

## 验证

- `node tests/campaign.test.cjs`：六关即时动作通关、体力与蓄势、打断与破绽、装备、预警与躲避。
- `node tests/results.test.mjs`：使用实际接口与 SQLite 检查保存、排名、旧战绩兼容、移除模式与访问边界。
- `node tests/results-api.test.mjs`：仅连接本地预览，验证完整 HTTP 流程。
- `node node_modules/typescript/bin/tsc --noEmit`

发布使用 Sites 工作流，保留原项目和公开访问权限。测试数据只写入本地数据库。生产库通过追加迁移保留既有战绩。
